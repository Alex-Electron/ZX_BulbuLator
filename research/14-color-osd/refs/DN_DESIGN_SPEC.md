# 0. ЦВЕТА (палитры) — точная спецификация

Атрибут = 1 байт `bg<<4 | fg` (blink OFF → старший ниббл = полный 4-битный фон 0..15, НЕ мигание).
`#define ATTR(bg,fg) (uint8_t)(((bg)<<4)|((fg)&0x0F))`. У нас FG(i)=DOS[i] (opaque), непрозрачный фон цвета i = FG(i).

**16 цветов DOS (VGA):** 0 чёрн `000000` · 1 син `0000AA` · 2 зел `00AA00` · 3 циан `00AAAA` · 4 красн `AA0000` · 5 пурп `AA00AA` · 6 корич `AA5500`(⚠не AAAA00) · 7 св.сер `AAAAAA` · 8 тёмн.сер `555555` · 9 ярк.син `5555FF` · 10 ярк.зел `55FF55` · 11 ярк.циан `55FFFF` · 12 ярк.красн `FF5555` · 13 ярк.пурп `FF55FF` · 14 жёлт `FFFF55` · 15 бел `FFFFFF`.

Резолвинг: `attr = AppPalette[ DialogPalette[ ViewPalette[state] ] ]` (tview.cpp:484 getColor → mapcolor.cpp:20, 1-based).

## 🔴 ГЛАВНОЕ РАСХОЖДЕНИЕ: кнопки — зелёные (наш выбор) vs тёмно-серые (DNAPP.PAS)

## 1. TFrame — рамка окна/диалога (tframe.cpp, framelin.cpp, tvtext1.cpp:71-81)
Активное окно (sfActive) → ДВОЙНАЯ рамка (f=9); пассивное/drag → одинарная.
- Активная (двойная): ╔═╗ ║ ╚═╝ = `C9 CD BB / BA / C8 CD BC`
- Пассивная (одинарная): ┌─┐ │ └─┘ = `DA C4 BF / B3 / C0 C4 D9`
- T-стыки: ┬`C2` ┴`C1` ├`C3` ┤`B4` ┼`C5`; двойные ╤`D1` ╧`CF` ╟`C7` ╢`B6`
- Заголовок: центр верхней рамки, `═ title ═` (по 1 пробелу вокруг), цвет активн. 0x0004 / пассивн. 0x0002; резерв места width-10 (-6 если close|zoom, -4 если номер).
- Иконки (только sfActive): закрыть `[■]`=`5B FE 5D` @col2 · zoom `[↑]`=`5B 18 5D` @width-5 · unzoom `[↕]`=`5B 12 5D` · grow `└─`@0 / `─┘`@width-2 · номер окна `'0'+n` @width-3 (или width-7 при zoom).

## 2. Тень окна (tview.cpp:35, tvwrite.cpp:62-85)
shadowSize = {2,1} (2 колонки вправо, 1 строка вниз), shadowAttr = 0x08. Символ НЕ меняется — только атрибут → 0x08 (тёмно-серый на чёрном = затемнение). 2 колонки по X компенсируют вытянутость клетки. Флаг sfShadow (окна/диалоги/меню).

## 3. TButton — кнопка (tbutton.cpp:66-164, tvtext1.cpp:116-117)
- shadows = `DC`▄ `DB`█ `DF`▀; markers = `[ ]` ТОЛЬКО в mono.
- Геометрия: s=size.x-1; тело залито пробелами (cButton); колонка 0 = инсет тени; правый край при y==0 → `DC`▄, ниже → `DB`█; низ = `DF`▀; текст с col 1, центр `l=(s-len-1)/2`.
- **default/normal/focused РАЗЛИЧАЮТСЯ ТОЛЬКО ЦВЕТОМ** (цветной режим): normal 0x0501, default 0x0602, selected/focused 0x0703, disabled 0x0404. **Стрелок у default в цветном TV НЕТ.**
- Маркеры только mono: `[`/`]` @col1/col s-1 + specialChars: selected `»`0xAF/`«`0xAE; default `→`0x1A/`←`0x1B.
- **ВАЖНО для нас:** реальный DOS Navigator (по скриншоту владельца) показывает циан-треугольники у default-кнопки И в цвете — владелец их хочет. Наша реализация: треугольные глифы ►/◄ по КРАЯМ кнопки (первая/последняя ячейка), текст по центру, позиции не зависят от длины текста; ширина кнопки не зависит от фокуса.
- Ширина кнопок в стандартных диалогах ОДИНАКОВАЯ: msgbox все кнопки TRect(0,0,10,2) = ширина 10, зазор 2, ряд центрируется; inputBox тоже 10, шаг 12.

## 4. TInputLine — поле ввода (tinputli.cpp:134-161, tvtext1.cpp:106-107)
- rightArrow `10`► leftArrow `11`◄. Заливка пробелами (норм getColor1 / фокус getColor2); данные с col 1. Прокрутка вправо `10` @col size.x-1 если текст не влезает; влево `11` @col0 если firstPos>0. Выделение цветом getColor3. Курсор @displayedPos-firstPos+1.
- combo/history icon: `▐↓▌` = `DE 19 DD`.
- **DN input line — ЧЁРНЫЙ фон** (по скриншоту), не синий.

## 5. TCheckBoxes/TRadioButtons (tcluster.cpp:80-129, tcheckbo/tradiobu, tvtext1.cpp:67,111)
- CheckBox: icon ` [ ] `, marker ` X` → `[ ]`/`[X]` (X=`58`).
- Radio: icon ` ( ) `, marker ` •` → `( )`/`(•)` (•=`07`).
- Раскладка: `‹пробел›[‹маркер›]‹пробел›‹текст›` — иконка col..col+4, текст с col+5, курсор на col+2. Колонка = maxlen+6. Цвета: норм 0x0301, выбр. 0x0402, disabled 0x0505. Mono: `»`/`«` вокруг.

## 6. TScrollBar (tscrlbar.cpp:60-81, tvtext1.cpp:113-114)
- Верт (size.x==1): ▲`1E` ▼`1F`, жёлоб ▒`B1`, ползунок ■`FE`, пусто ▓`B2`.
- Гориз: ◄`11` ►`10`, жёлоб ▒`B1`, ползунок ■`FE`, пусто ▓`B2`.
- chars[0]=стрелка-нач (цвет2), [1]=стрелка-кон (цвет2), [2]=жёлоб-страница ▒ (цвет1), [3]=ползунок ■ (цвет3), [4]=пусто ▓. Если листать нечего — жёлоб ▓`B2`. Мин длина 3.

## 7. TMenuBar/TMenuBox (tmenubar.cpp:48-92, tmenubox.cpp:73-123, tvtext1.cpp:69)
- MenuBar: строка пробелами (cNormal 0x0301); пункты ` Имя ` (пробел с боков), x+=len+2, без разделителей. Выбор 0x0604, disabled 0x0202.
- MenuBox: одинарная рамка ` ┌─┐ / │ │ / ├─┤ / └─┘ ` (ведущий/замыкающий пробел под тень); текст @col3; подменю ► `10` @size.x-4; шорткат справа @size.x-3-len; разделитель ` ├───┤ `. Выбор 0x0604 полосой col 2..size.x-2. Размер: ширина max(len+6; +3 подменю; +param+2), мин 10; высота = пункты+2. Тень.

## 10. Общие метрики
- Отступ контролов от рамки 2–3 колонки. Кнопки — нижний ряд, центр (msgbox) или справа (inputBox), шаг = ширина+2. Tab = порядок вставки. Enter→cmDefault (default-кнопка), Esc→cmCancel. Диалог: dpGrayDialog, wfMove|wfClose.
- specialChars = `»`AF `«`AE `→`1A `←`1B (mono-маркеры фокуса/default).
- TListViewer: текст @col+1, разделитель колонок │`B3` @правый край (цвет5), фокус = цвет-полоса getColor3, без символа-маркера в цвете.
- TLabel: текст @col1, активн. 0x0402 / иначе 0x0301. TStaticText: `\x03` = центрирование строки, `\n` перенос.
