# BulbuLator — Музыкальный плеер: заметки и планы (улучшение + расширение)

> Создано 2026-07-06. Владелец: «вроде аудио хорошо играет, записываем идею, потом будем следить — я ещё буду внимательно слушать в будущем; пока делаем заметки/планы на будущее, идём дальше». Т.е. движок стабилен на текущем этапе, дальнейшая работа по плееру — отложенные фичи. Низкоуровневый АУДИО-движок и стабильность → [[AUDIO_ENGINE_PLAN]]. Общее состояние → [[HANDOVER]].

## Статус сейчас (v0.14.14, на железе)
- Играет **PSG / WAV / MP3** стабильно. Фаза P0 неблокируемого аудио сделана (консюмер FIFO-тактируемый, SLIP удалён, тишина на underrun, продюсер до high-watermark). Владелец слушал — **«вроде хорошо»**, оставил на мониторинг (вслушиваться в будущем на предмет ускорений/дропов — починенный баг был «~0.5с ускорение раз в 30-40с»).
- UI плеера пока = только строка статуса в DN-браузере (row 22: ►/‖ + полный путь + M:SS/M:SS + прогресс-бар, бегущая строка для длинных).

## 🎛️ Планы: РАСШИРЕНИЕ плеера (UX/фичи, на будущее)
1. **Модальное DN-окно плеера по Enter** (главная хотелка владельца, «делать сразу правильно»). Дизайн (из родного DN `CDPLAYER.PAS` + OCP/cmus референсы, разобрано сворм-агентом):
   - Окно **50×18**: имя трека (шрифт) / время elapsed–total / **seek-бар ▓░** / **спектр-анализатор 40 полос × 8 строк** (FFT-512 Hann + лог-биннинг + градиент green→yellow→red ПО СТРОКЕ + peak-hold ▔, 25-30fps ТОЛЬКО в фокусе) / транспорт `►◄◄►►■ ‖` / режимы loop+display / **теги ID3 + метаданные**. Zoom → компакт 50×8.
   - **Кнопка «в фон»** (Esc) → окно прячется, остаётся минимальный нижний бар (как сейчас в статус-строке). F-клавиша → окно снова. Аудио-движок всегда жив (модель DN `RegisterToBackGround`); анализатор считается только когда окно в фокусе.
   - **Reusable из DN:** `GetDigit` 3×3 блок-шрифт (▄▀█) для крупных цифр времени; `▓░` gauge; серая dialog-палитра; фоновая модель. Спектр sub-cell = свой ARGB-шрифт U+2581..2588 (▁▂▃▄▅▆▇█). Свой глиф `‖` для паузы.
2. **Режимы воспроизведения** (задаются в ОПЦИЯХ, соблюдаются даже когда окно скрыто И вышли из папки): один файл→стоп · вся папка по-очереди · один зациклен. Нужен persistent-снимок плейлиста/режима, не привязанный к текущей папке.
3. **Визуализация (OCP-стиль):** текст-спектрограмма (готова к #1), осциллоскоп, для трекеров — канальные скопы.
4. **Tape-плеер** (аналог, окно 48×12): Block N/всего + name/type + gauge текущего блока + общий + ZX loading-полоса.
5. **Volume +/- на фоне** — показывать в плашке паузы (транзиентный оверлей на +/-), без вызова меню.
6. **Скиновая система плеера:** DN-текст / OCP-виз / Winamp-скин / магнитофон-анимация (osd_skin/player_skin, ARGB — любой скин).
7. **Встроенный DN-тетрис** — играть во время музыки.

## 🔩 Планы: УЛУЧШЕНИЕ движка (→ детально [[AUDIO_ENGINE_PLAN]])
- **Все форматы, вкл. lossless** (цель владельца): FLAC/Opus/Vorbis/трекеры через **кодек-плагин интерфейс** (open/read/close/duration/sr/seek). Кольцо и ресемплер уже формат-агностичны. **VBR+CBR MP3 уже точны** (длительность из Xing/Info/VBRI up-front).
- **Стабильность «до 150%»:** P1 высший GIC-приоритет таймера · P2 предзагрузка файла в RAM (CDJ long-buffer) · P3 кооперативный `player_pump()` в скане/config-save · **CPU1 = выделенное аудио-ядро** (для FLAC/DSP-запаса; XAPP1079). Пороги/watermark'и и обоснование — в [[AUDIO_ENGINE_PLAN]].

## 👂 Что мониторить (владелец слушает)
- Любые ускорения/замедления/дропы (починенный баг: SLIP по стенным часам при SD-сталле). Если вернётся — сразу P2/P3/CPU1.
- Щелчки на старте/паузе/стопе/EOF (fade Q8 должен их снимать).
- Точность времени на VBR (elapsed из реально сыгранных сэмплов).
