# BulbuLator — МАСТЕР-ПЛАН к идеалу (NES + Spectrum + джойстики + TR-DOS)
Цель владельца: **лучшее retro-решение в мире по цене/качеству.** База — EBAZ4205 (Zynq-7010, ~$15-30).
Синтез всего research: NES_FPGA_ANALYSIS, INSTANT_LOAD_SURVEY, CORE_DESCRIPTOR_DESIGN, nes-fpga-port-plan.

## 1. SPECTRUM — идеал
Машины: 48/128/Pentagon (есть, Atlas-ядро B0061) + 48-MiSTer (B0059). Снег-тоггл (есть).
**a) Мгновенная загрузка лент до >99%** (INSTANT_LOAD_SURVEY): наш промах = темп-эвристика как РЕШЕНИЕ.
  - A. Жёсткий PC-трап $0562 LD-BYTES + gate (genuine 48K-ROM, нет shadow-ROM, тип блока standard, PILOT, длина==DE+2) → детерминированно все стандарт-загрузчики (как esxdos). БЫСТРО, чинит hit-rate.
  - B. Turbo-block (TZX 0x11) параметрический инжект.
  - C. SMART-2 = ARM-Z80-интерпретатор (SkoolKit sim-load, ~43 ускорителя) → snapshot-inject → >99% включая кастом-турбо. Крупно, но это «идеал».
  - D. Аппаратный турбо MiSTer smart_tape (cores/zx-mister/rtl/tape.sv) — опция на реальном Z80.
**b) DivMMC/esxdos** — divmmc.v уже в cores/zx-mister → нативный esxdos (browser/.tap/.sna/dot-cmd), backing SD через ARM.
**c) TR-DOS/Beta Disk** — см. раздел 4.
**d) Все джойстики** — см. раздел 3.

## 2. NES/FAMICOM/ДЕНДИ — идеал (В РАБОТЕ)
База NESTang (fit 29% LUT, ВСЕ мапперы). Порт top в процессе (git baseline+steps).
Идеал: (1) играющая игра [Раунд-1 NROM в BRAM]; (2) все картриджи [Раунд-2 DDR-память + полный маппер-набор — влезает]; (3) мультикарты/Денди (мапперы 15/225/255); (4) регион NTSC/PAL/**Денди(50Гц)**; (5) палитра NES (.pal, нормальные цвета); (6) battery-save .sav; (7) FDS BIOS; (8) [позже] save-states/rewind (DDR-backed). Игры с SD как RetroPie (навигатор → .nes → играешь).
Шаги: см. HANDOVER_NES.md / мостик (nes_top → build → ARM-загрузчик → synth → JTAG-дамп кадра).

## 3. ДЖОЙСТИКИ — идеал (универсальный ввод)
Универсальный 8-бит пад JOY_STATE (2 игрока) = общий слой. + СЕЛЕКТОР ТИПА ГОСТЯ:
  - ZX: Kempston(0x1F,8-бит 000FUDLR+доп.fire), Sinclair 1/2 (клавиши 6-0/1-5), Cursor/Protek, Fuller(0x7F).
  - NES/Денди: серийный A/B/Select/Start+D-pad (есть в nes_wrap). Sega DB9 (2/3/6 кнопок). C64/Atari DB9.
Источники: клавиатура-мап (есть, joymap) + физпад (USB/GPIO — будущее, вытесняет клаву). Подписи/дефолты кнопок — per-core (из дескриптора). Мастер произвольного назначения всех 8 бит (есть, визард v145) → доделать per-core подписи + hardware-тест.

## 4. TR-DOS / BETA DISK — СЛЕДУЮЩЕЕ ПОСЛЕ NES
Beta 128 = WD1793 FDC + TR-DOS ROM (пейджится automap'ом на M1@0x3Dxx, out при выходе из 0x4000+, как DivMMC).
Диски .TRD (640КБ: 80 трек×2×16сект×256Б) / .SCL (компакт → конверт в TRD). Pentagon ВСЕГДА с Beta Disk (важно!).
Эмуляция: (1) проверить, есть ли Beta Disk/WD1793 в Atlas/zx-mister ядре (как divmmc.v) → переиспользовать; (2) иначе вендорить открытый WD1793 (есть в ZXUno/MiSTer); (3) TR-DOS ROM в банк; (4) ARM отдаёт сектора из .TRD на SD через AXI (как tape/divmmc backing); (5) навигатор .trd/.scl → mount → RUN. Мгновенно (диск и так быстрый).

## 5. СКВОЗНОЕ (всё через дескриптор ядра — CORE_DESCRIPTOR_DESIGN)
Видео: фикс 1280×720 у ВСЕХ ядер (монитор не пересинхронизируется); нативная геометрия+палитра — поле дескриптора; fb_line_disp SRC_BPP+палитра (готово к расширению). Аудио: единый микс. Меню: .CORE-сайдкар → динамическое меню при выборе ядра. Save-states/rewind — DDR-backed, позже.

## ПРИОРИТЕТ (дорога)
1. **NES → играющая игра** (дедлайн завтра) — top/build/ARM/synth/validate.
2. **Мгновенная загрузка A** (жёсткий $0562-трап) — быстрый большой выигрыш качества ZX.
3. **TR-DOS** (Beta Disk) — по просьбе владельца после NES.
4. NES Раунд-2 (DDR, все мапперы, Денди-регион, палитра, save).
5. SMART-2 (>99% загрузка), esxdos-эмуляция, дескриптор-меню Фаза 1, физ-джойстики.
6. Save-states/rewind, шейдеры/скейл-опции, сетевой KVM.
Каждый шаг: git-коммит (откат), фиксация в мостик/память (эстафета).

## ПРОВЕРКА «ЛУЧШЕЕ В МИРЕ» (критерии приёмки)
- FPGA-точность ядер (не софт-лаг) ✔ (реальные ядра).
- Мгновенная загрузка ≥ esxdos/ZEsarUX (>99%) — план A+C.
- Все картриджи NES + все ленты/диски ZX (tap/tzx/trd/scl/tap-instant).
- Все популярные джойстики.
- Hot-swap ядер с SD (✔ есть).
- Цена в 5-10× ниже конкурентов при равной/лучшей точности.
