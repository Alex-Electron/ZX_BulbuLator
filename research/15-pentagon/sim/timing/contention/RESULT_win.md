## 2. Прямой прибор: форма окна независимо от программы

Программа: `harness/prog/marker_5000.bin` по 0x5000 (банк 5, контендуемое ОЗУ): `EI; HALT` в цикле, то есть
процессор непрерывно делает M1 по 4 T по контендуемому адресу. Прибор печатает строку растра по пикселям
(`cn` = `dut.Video.cn` на каждом `ne7M0`, индекс = `hc`) и по тактам (на каждом `pe3M5`: `vduC`,
`vduC && cpuck`, `contend==0`; индекс = номер `pe3M5` в строке, `pe3M5` стоят на чётных `hc`, индекс i ↔ hc = 2i).
Логи: `logs/run_MACHINE=48_PROG=..-marker_5000.bin_ORG=5000_FRAMESTAT=1_QUIET=1_WINLINE={0,100,191}_RUNUS=45000.log`,
то же для `MACHINE=128 WINLINE=0` и `MACHINE=PENT WINLINE=100`.

48K, строка 0 (строки 100 и 191 — байт в байт те же строки, только k другой):

```
по пикселям (индекс = hc, 448 px):
  cn    : ...############....############....############....############....############....############....############....############....############....############....############....############....############....############....############....############...(дальше 0 до конца строки)
  paper : ............PPPP…(256 px)…PPPP....…  бумага на выходе r/g/b с hc=12 по hc=267
по тактам (индекс = номер pe3M5 в строке, 224 T):
  vduC        : ..######..######..######..######..######..######..######..######..######..######..######..######..######..######..######..######................(96 свободных)
  contend==0  : ....####....####....####....####....####....####....####....####....####....####....####....####....####....####....####....####................
```

| первый импульс `pe3M5` с `vduC=1` после /INT: k (t = k−2) | **14338 (t 14336)**, hUla 5, vCount 0 | **14364 (t 14362)**, hUla 5, vCount 0 | 64 (vCount 240; окно есть, гейт выключен) |

| потерянные такты `HALT`-цикла в группе 8 T | индексы 4..7: 4 из 8 (M1 по 4 T садится в фазу «T1 на hc 6» и платит 4) | то же | нет |

Как читать «+1» у 14338/14364: импульс k завершает такт k−1. Импульс 14338 (t=14336) — первый погашаемый,
он удлиняет такт, начавшийся на t=14335. По Fuse задержка 6 назначается такту, НАЧАВШЕМУСЯ на 14335. То есть
наше окно на импульсах стоит ровно там, где нужно, чтобы цикл с T1 на t=14335 получил 6, на 14336 — 5 и т. д.
(проверено программой в разделе 3). У 128K соответственно 14361.

Пиксель против окна: у нас бумага выходит на видеовыход на 9 px позже первого пикселя `cn` (hc 3 → hc 12).
У Сергея (`REFERENCE_SERGEY.md` §7.2) `CONTENTION` и `picture` поднимаются на одном count'е, а бумага дальше идёт
через 9 пиксельных стадий (`pap_tap = 9`) — тоже +9 px к выходу. Сопоставление «пиксель ↔ INT» в тактах — предмет
стенда intgeo, здесь только зафиксировано.

Гистограмма потерь по фазе `hUla[3:1]` за 45 мс `HALT` в 0x5000 (48K): фазы 0,1 (hUla 0..3) — 0 и 0; фазы 2..7 —
459, 900, 7171, 7457, 7539, 7548. Потери только внутри окна `hUla[3]||hUla[2]`; неравномерность — свойство
4-тактного цикла `HALT`, не окна.
