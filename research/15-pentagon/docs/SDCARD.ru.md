# Карта памяти: что где лежит

Всё, что описано ниже, взято из кода прошивки, а не из памяти: пути зашиты в `../arm/loader_main.c`,
ссылки на строки даны там же. Каталоги, которых нет, прошивка просто не найдёт — она не падает, но и
соответствующая возможность работать не будет.

## Обязательный минимум

```
0:/
├── BOOT.BIN                загрузочный образ: начальный загрузчик + ядро + прошивка оболочки
└── bulbulator.ini          настройки (появится сам после первого «Save config»)
```

`BOOT.BIN` читает **не прошивка, а BootROM самой платы**. Это единственный файл, без которого плата не
поднимется вообще. Всё остальное — по потребности.

## Полная раскладка

```
0:/
├── BOOT.BIN                          образ загрузки
├── bulbulator.ini                    настройки; пишется ТОЛЬКО по явному «Save config»
│
├── CORES/                            ядра машин, по одному файлу на ядро
│   ├── ATLAS.BIT.BIN                 ZX: 48K, 128K и Пентагон 1024 — все три на одном ядре
│   ├── MISTER48.BIT.BIN              необязательно: ядро MiSTer-48, проектом не развивается
│   └── NES.BIT.BIN                   NES / Денди
│
├── ROMS/                             наборы ПЗУ машины
│   ├── BUILTIN.ROM                   явный фолбэк; если файла нет, берётся ПЗУ, вшитое в битстрим
│   ├── <любое имя>.ROM               наборы: список строится ОБХОДОМ каталога при каждом входе
│   │                                 в подменю машины, выбор — опция ROM SET
│   ├── ESXMMC.ROM                    ПЗУ DivMMC / esxDOS
│   └── GS105B.ROM                    запасное место для прошивки карты General Sound
│
├── GS/
│   └── GS105B.ROM                    основное место прошивки карты General Sound
│
├── DIVMMC/                           DivMMC в режиме «папка»: карта собирается из этого каталога
├── DIVMMC.IMG                        DivMMC в режиме «образ»
├── SDCARD.IMG                        образ карты для Z-Controller
│
├── NES/                              картриджи .nes
└── …                                 всё остальное — как удобно: игры, демки, дискеты, музыка
```

Пути к образам можно переназначить в настройках машины; в таблице указаны умолчания.

## Что куда класть из этого репозитория

| Файл отсюда | Куда на карту |
|---|---|
| `../bitstreams/BOOT_B0198_v0.15.446.BIN` | `0:/BOOT.BIN` |
| `../bitstreams/ATLAS_B0198.bit.bin` | `0:/CORES/ATLAS.BIT.BIN` |
| `../bitstreams/NES_CE29.bit.bin` | `0:/CORES/NES.BIT.BIN` |
| `../roms/*.ROM` — наборы ПЗУ машины, происхождение в `../roms/PROVENANCE.md` | `0:/ROMS/` |
| `../roms/GS105B.ROM` — прошивка карты General Sound | `0:/GS/GS105B.ROM` |
| `../roms/ESXMMC.ROM` — ПЗУ DivMMC | `0:/ROMS/ESXMMC.ROM` |

Самому esxDOS нужны ещё его каталоги `SYS` и `BIN` из дистрибутива с [esxdos.org](http://www.esxdos.org/): они
кладутся на карту DivMMC, то есть в `0:/DIVMMC/` (режим «папка») или внутрь `0:/DIVMMC.IMG` (режим «образ»).

Собрать всё это самому из исходников — [`../BUILDING.md`](../BUILDING.md).

## 🥇 Обновляя ядро ZX, меняй ОБА файла

Оболочка перезагружает ПЛИС с карты **только при смене ИМЕНИ ядра**, а у 48K, 128K и Пентагона имя
одно — `ATLAS`. Холодный старт вообще поднимает битстрим из `BOOT.BIN` и перезагрузку ПЛИС не делает.

Значит менять надо **и `0:/CORES/ATLAS.BIT.BIN`, и `0:/BOOT.BIN`**. Иначе одно из двух: либо холодный
старт останется на старом ядре, либо поход в другую машину и обратно молча вернёт прежний
`ATLAS.BIT.BIN`. Это стоило полдня поисков «почему правка то есть, то нет».

## Файловая система

**FAT32 по умолчанию.** FAT16 выбирался когда-то по нашей простоте и трижды выставил цену: предел
записей в корне, невидимость для чужих FAT32-драйверов (двух плееров) и зависание одного файлового
менеджера из ПЗУ. На FAT32 esxDOS читает файловую систему наравне.

**FAT16 нужен ровно одному** — браузеру длинных имён Bob Fossil: он разбирает таблицу сам и читает
поле числа записей корня буквально, требуя ровно 512, а у FAT32 этого поля нет вовсе. Для режима
«папка» у DivMMC есть отдельные опции: файловая система и число записей корня.

## Тонкости, оплаченные временем

- **Имя файла обрезается на 96 знаках, молча.** Сам файл пишется и читается по полному имени, но в
  списке видно только 96 знаков — у длинных имён из TOSEC отрезает как раз расширение, и запись
  выглядит как «файла нет». Такие файлы стоит переименовывать.
- **Следи за свободным местом.** При нехватке места запись отчитается успехом, записав обрезок. Если
  так пострадает ядро в `CORES/`, следующая смена машины поднимет обрезок. Каталог `CORES/` ещё и
  копит резервные копии по 1.2 МБ.
- **`bulbulator.ini` пишется только вручную.** Живые правки применяются сразу, но на карту не идут,
  пока не выбран «Save config». Значит ручное сохранение перетирает то, что записал кто-то ещё.
- **Набор ПЗУ, залитый с карты, не восстанавливается ни железным сбросом, ни пунктом RESET** — вайп
  трогает только ОЗУ машины. Вернуть вшитое можно лишь перезагрузкой ядра, то есть выбором
  `ROM SET = BUILT-IN`.
- **Размер файла — не признак того, что это ПЗУ Спектрума.** Прошивка карты General Sound весит ровно
  65 536 Б, то есть ровно четыре страницы по 16 КБ, и размерный фильтр проходила: она попадала в
  список наборов машины, и её можно было выбрать. Теперь набор проверяется по содержимому.
