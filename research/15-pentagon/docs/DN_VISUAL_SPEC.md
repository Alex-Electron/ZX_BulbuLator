# DN (Turbo Vision) визуальный эталон — глифы/геометрия/логика (палитра НАША, ARGB)

> 2026-07-06. Извлечено сворм-агентом из исходников DN (maximmasiutin fork `scratchpad/dn/Dos-Navigator/`). Правило владельца: **палитра НАША (полный ARGB, текущие цвета оставляем)**, из DN берём только СТРУКТУРУ/ГЛИФЫ/ЛОГИКУ отрисовки. Char-коды — decimal CP437/CP866 (= наши CP866-ячейки). Цвет — только относительный акцент (что ярче/инверсное/тусклее). Сетка 80×25, atr=`bg<<4|fg`. Применяется в переносе OSD в DN-интерфейс: [[HANDOVER]], [[session-step14-4-dn-browser]].

## 1. Рамка окна/диалога — TFrame (VIEWS.PAS:2036-2109)
Пассив (неактивное окно) = ОДИНАРНАЯ, актив/диалог = ДВОЙНАЯ.
- **Одинарная:** ┌218 ─196 ┐191 │179 └192 ┘217, интерьер = space(32) в цвете рамки.
- **Двойная:** ╔201 ═205 ╗187 ║186 ╚200 ╝188.
- Интерьер окна ЗАЛИВАЕТСЯ пробелами цвета рамки (серый диалог = цвет рамки).
- **Заголовок**: центр верхней кромки, `start=(W-len)>>1`, пробел цвета заголовка в start-1 и start+len, текст между. Активный ярче.
- **Иконки (только актив):** Close в col 2 = `[`91 `■`254 `]`93 (скобки цвет рамки, ■ акцент). Zoom в col W-5 = `[`91 `↑`24 `]`93 (макс → ↕18). Grip (если growable) в col W-2 = ─196 ┘217.

## 2. Тень — ShadowSize (2 вправо, 1 вниз) (VIEWS.PAS:521,862)
Правило TV: НЕ рисует пробелы, а МЕНЯЕТ атрибут подлежащих ячеек на $08 (тёмно-серый на чёрном). **Для ARGB: затемнить то, что под тенью** (умножить RGB ~×0.5, alpha сохранить). Даёт каждый TWindow/TDialog и каждый dropdown TMenuBox. L-форма: правые 2 колонки (строки y+1..y+h) + нижняя строка (col x+2..x+w+1).

## 3. Скроллбар — TScrollBar (VIEWS.PAS:2180-2252)
- Верт: ▲30 ▼31, страница ▒177, ползунок ■254, неактивная ▓178. Гориз: ◄17 ►16, тот же fill.
- **Ползунок DN = ВСЕГДА 1 ячейка** (по PgStep НЕ масштабируется). Pos = round((Value-Min)*(GetSize-3)/(Max-Min))+1, диапазон 1..GetSize-2. Max==Min → весь ▓178 без ползунка.
- **⚠️ У НАС (одобрено владельцем): сплошной █(0xDB), пропорциональный ползунок, БЕЗ dither-«зебры»** (▒/▓ — это дизер DOS). Берём из DN только ГЛИФЫ СТРЕЛОК (30/31 — наш браузер уже так) и логику позиции; заливка/ползунок — сплошные, наша палитра (ползунок ярче, шахта тускло-серая).

## 4. Меню-бар — TMenuBar (MENUS.PAS:875-915)
X с 1 (1 пробел слева). Каждый пункт `[space]name[space]`, X+=len+2 → 1 пробел перед первым, 2 между пунктами. Хоткей-буква (`~x~`) акцентом. Выбранный (открытый) пункт — 3 ячейки инверсным цветом. Disabled тускло.

## 5. Выпадашка — TMenuBox (MENUS.PAS:934-1028)
Рамка ОДИНАРНАЯ, вставлена на 1 (col 0 и W-1 пустые, │ в col 1 и W-2): top ` ┌───┐ `, item ` │ … │ `, separator ` ├───┤ ` (195/180), bottom ` └───┘ `. Текст пункта с col 3. Выбранный: заливка col 2..W-3 инверсным (│ рамки остаются нормальными). Субменю ► (16) в col W-4 (maximmasiutin — голый ►, angelbbs `[►]`). Шорткат (F3) справа, конец в col W-4. Разделитель = пункт с пустым именем. Размер: W=max(10, шире_пункта+6 (+3 субменю | +len_шортката+2)), H=2+кол-во.

## 6. Кнопка — TButton (DIALOGS.PAS:1189-1278)
ShowMarkers=False → ЗАЛИВНАЯ кнопка + тень (НЕ `[ OK ]`). Грань = пробелы цвета кнопки, метка по центру `L=(W-1-len)div2`. Правая тень col W-1: верх ▄220, ниже █219 (цвет тени). Низ (строка H-1): ▀223 (тень). **Default/focused: ►16 в col1, ◄17 в col W-2** обрамляют метку (нажата → сдвиг +1). Default = ярче.

## 7. Инпут-лайн — TInputLine (DIALOGS.PAS:774-806)
Поле = пробелы цвета поля; фокус НЕ меняет цвет (показывается КУРСОРОМ). Переполнение справа: ►16 в последней col; слева: ◄17 в col0 (при фокусе). Пароль: маска ■254.

## 8. Кластер radio/checkbox — TCluster (DIALOGS.PAS:1497-1538)
Radio: ` ( ) ` → ` (•) ` (маркер •7 в col+2). Checkbox: ` [ ] ` → ` [X] `. Метка с col+5, `~хоткей~`. Текущий+фокус — ярче.

## 9. StaticText/Label/List/Панель
- StaticText: один цвет, wrap; ctrl-char 3=центр строки, 13=разрыв.
- Label: текст с col1 (1 отступ), при фокусе связанного контрола ЯРЧЕ.
- ListViewer: ColWidth=W/NumCols+1; разделитель колонок │179; фокус+строка=курсор-бар, tagged=выделен, без фокуса весь список тускнеет.
- Файл-панель: разделитель колонок │179; курсор-строка видна ТОЛЬКО в фокусной панели; tagged (Ins) = √251 в name+8.
- Десктоп: заливка ░176, тускло.
